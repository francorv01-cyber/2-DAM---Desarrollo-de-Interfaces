# Proceso de creación · Guía de viajes de mi país Perú

Web estática (HTML + CSS + JavaScript, sin dependencias) que documenta paso a paso cómo se creó la guía de viajes de Perú.

## Ver en local
Abre `index.html` con doble clic. (Las tipografías de Google Fonts necesitan Internet; sin ellas se usa una tipografía por defecto.)

## Subir a GitHub Pages
1. En tu repositorio, sube la carpeta completa `proceso-peru` (Add file → Upload files, arrastrando la carpeta).
2. Comprueba que en Settings → Pages la rama es `main` y la carpeta `/ (root)`.
3. El enlace será: `https://francorv01-cyber.github.io/2-DAM---Desarrollo-de-Interfaces/proceso-peru/`

## Estructura
```
proceso-peru/
├── index.html
├── css/style.css
├── js/main.js
└── assets/img/   (capturas extraídas del PDF)
```
